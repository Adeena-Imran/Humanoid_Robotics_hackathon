# Data Model: Module 3 - Sensors and Perception in Humanoid Robots

**Date**: 2025-12-07
**Feature**: [Sensors and Perception in Humanoid Robots](specs/002-humanoid-perception/spec.md)

## Key Entities and Relationships

### 1. Sensor

*   **Description**: A device that detects and responds to some type of input from the physical environment.
*   **Fields**:
    *   `id`: Unique identifier for the sensor.
    *   `name`: Descriptive name (e.g., "Front Camera", "Left IMU").
    *   `type`: Type of sensor (e.g., "CAMERA", "IMU", "LIDAR", "FORCE_TORQUE", "TACTILE").
    *   `specifications`: Object containing sensor-specific parameters (e.g., `resolution` for camera, `frequency` for IMU, `range` for LiDAR).
    *   `mountPoint`: Pose describing its location and orientation on the robot.
*   **Relationships**: Generates `Sensor Data`. Mounted on a `Humanoid Robot Model` (from Module 2).

### 2. Sensor Data

*   **Description**: Raw or processed information acquired from sensors.
*   **Fields**:
    *   `id`: Unique identifier for the data instance.
    *   `timestamp`: Time when the data was recorded.
    *   `type`: Type of data (e.g., "IMAGE", "POINT_CLOUD", "IMU_READING", "FORCE_READING").
    *   `value`: Data content (format depends on `type`, e.g., base64 string for image, array of points for point cloud).
    *   `sourceSensorId`: Reference to the `Sensor` that generated this data.
*   **Relationships**: Generated by a `Sensor`. Processed by `Perception Algorithms`.

### 3. Perception Algorithm

*   **Description**: A computational method used to extract meaningful information from `Sensor Data`.
*   **Fields**:
    *   `id`: Unique identifier for the algorithm.
    *   `name`: Name of the algorithm (e.g., "EKF_Localization", "OccupancyGrid_Mapping", "YOLO_ObjectDetection").
    *   `type`: Category of algorithm (e.g., "LOCALIZATION", "MAPPING", "OBJECT_RECOGNITION").
    *   `inputDataTypes`: List of `Sensor Data` types it can process.
    *   `outputDataTypes`: List of data types it produces (e.g., `Pose`, `Environmental Map`, `Feature` list).
    *   `parameters`: Configuration parameters for the algorithm.
*   **Relationships**: Processes `Sensor Data`, can produce `Environmental Map` and `Feature` entities.

### 4. Environmental Map

*   **Description**: A representation of the robot's surroundings, constructed from `Sensor Data` via `Perception Algorithms`.
*   **Fields**:
    *   `id`: Unique identifier for the map.
    *   `type`: Type of map (e.g., "OCCUPANCY_GRID", "FEATURE_MAP").
    *   `resolution`: Spatial resolution of the map.
    *   `data`: Actual map content (e.g., 2D/3D grid of probabilities, list of landmarks).
    *   `creationTimestamp`: Time when the map was generated or last updated.
*   **Relationships**: Generated by `Perception Algorithms`. Used by `Localization Algorithms`.

### 5. Feature

*   **Description**: A distinct and identifiable characteristic extracted from `Sensor Data`, used for perception tasks.
*   **Fields**:
    *   `id`: Unique identifier for the feature.
    *   `type`: Type of feature (e.g., "CORNER", "EDGE", "POINT_CLUSTER", "LANDMARK").
    *   `location`: Spatial coordinates of the feature (e.g., `Vector3`).
    *   `descriptor`: A unique numerical signature of the feature, used for matching.
    *   `sourceDataId`: Reference to the `Sensor Data` from which it was extracted.
*   **Relationships**: Extracted by `Perception Algorithms` from `Sensor Data`. Used in `Localization` and `Mapping`.
