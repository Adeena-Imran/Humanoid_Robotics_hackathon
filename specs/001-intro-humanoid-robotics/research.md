**Decision**: The project will target the latest stable version of Docusaurus.
**Rationale**: Using the `npx create-docusaurus@latest` command ensures that we are always using the most up-to-date, stable, and feature-rich version of Docusaurus. This avoids being locked into an older version and benefits from the latest improvements and security fixes.
**Alternatives considered**: Specifying a fixed version of Docusaurus was considered but rejected. This would require manual updates to keep up with the latest features and could lead to a stale and less secure documentation site over time.
