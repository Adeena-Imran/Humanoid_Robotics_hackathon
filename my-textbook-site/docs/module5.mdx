## 4.2 Reinforcement Learning for Physical Systems

### A Quick Refresher
As we touched on in Module 1, Reinforcement Learning (RL) is a paradigm where an **agent** l
earns to make decisions by interacting with an **environment**. The agent takes **actions**,
 observes the new **state** of the environment, and receives a **reward** signal. Its goal i
s to learn a **policy** (a strategy) that maximizes its cumulative reward over time.        

### The Challenge of Physicality
Using RL for physical systems is far more difficult than for board games or video games.    
-   **Sample Inefficiency**: It can take millions or even billions of attempts for an agent 
to learn a complex task. This is impractical on real hardware.
-   **Safety and Cost**: A real robot can be damaged by the random, exploratory actions an R
L agent takes in the beginning. A single fall can be catastrophic.
-   **The "Sim-to-Real" Gap**: A policy trained in a perfect simulation may fail on a real r
obot due to subtle differences in physics, sensor noise, or motor delays.

This is why modern robotics RL relies almost exclusively on **highly realistic, parallelizab
le simulation**.

### Our Algorithm of Choice: PPO
For our project, we will use **Proximal Policy Optimization (PPO)**. PPO is a policy gradien
t method that has become a go-to algorithm for robotics.
-   **Why PPO?** It strikes a fantastic balance between sample efficiency, ease of implement
ation, and stability. Unlike some other methods, it avoids taking destructively large steps 
during training, which is crucial for preventing the learning process from collapsing.

## 4.4 Project Part 2: The Training Pipeline

With the environment defined, we now bring in the RL agent to learn from it.

### The RL Agent: Our "Mind"
The agent consists of two parts:
1.  **The Policy Network**: A neural network (typically a Multi-Layer Perceptron or MLP) tha
t takes an `observation` as input and outputs an `action`. This is the "brain" that we are t
raining.
2.  **The Algorithm (PPO)**: The `stable-baselines3` library provides the PPO algorithm, whi
ch will be responsible for updating the weights of our policy network based on the rewards i
t receives from the environment.

### Hands-On: The Training Script
The script to run the training is surprisingly concise, as the libraries handle the heavy li
fting.
```python
import gymnasium as gym
from stable_baselines3 import PPO
import torch

# Our custom Isaac Sim environment
from humanoid_env import HumanoidWalkEnv

# 1. Instantiate the environment
# Isaac Sim's tools allow for creating multiple parallel environments
# to speed up training, but we'll start with one.
env = HumanoidWalkEnv()

# 2. Define the policy network architecture
# An MLP with two hidden layers of 256 neurons each
policy_kwargs = dict(
    net_arch=[256, 256]
)

# 3. Instantiate the PPO Agent
agent = PPO(
    "MlpPolicy",
    env,
    policy_kwargs=policy_kwargs,
    verbose=1,
    n_steps=2048,
    batch_size=64,
    gamma=0.99,

    # PPO-specific hyperparameters
    clip_range=0.2,
    ent_coef=0.0,
    learning_rate=3e-4,

    # Use GPU for training
    device="cuda"
)

# 4. Train the agent!
# This will run for 10 million simulation steps. On a good GPU, this
# might take a few hours.
agent.learn(total_timesteps=10_000_000)

# 5. Save the trained policy
agent.save("ppo_humanoid_walker")

print("Training complete!")
env.close()
```

### Running the Training
When this script is run, you can watch Isaac Sim in real-time. Initially, the robot will fla
il randomly and fall over constantly. But over millions of steps, as PPO refines the policy 
network, you will see a coherent and stable walking gait emerge, seemingly from nothing. Thi
s is the power of RL.

## 4.5 Project Part 3: Evaluation and Deployment

### Evaluating the Trained Policy
Once training is complete, we load our saved policy and watch it work.
```python
# script_to_evaluate.py
from stable_baselines3 import PPO
from humanoid_env import HumanoidWalkEnv

env = HumanoidWalkEnv()
agent = PPO.load("ppo_humanoid_walker")

obs, _ = env.reset()
for _ in range(5000):
    # Use deterministic=True for evaluation to get the best action
    action, _ = agent.predict(obs, deterministic=True)
    obs, reward, terminated, _, _ = env.step(action)
    if terminated:
        obs, _ = env.reset()
```
Running this will show your fully trained AI agent controlling the humanoid to walk, a direc
t result of the emergent behavior learned during training.
