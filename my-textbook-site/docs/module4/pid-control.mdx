# PID Control in Humanoid Robots

## Introduction

Proportional-Integral-Derivative (PID) control is one of the most common and robust control strategies used in various engineering applications, including robotics. Its simplicity and effectiveness make it a foundational concept for controlling robot joints, motors, and even higher-level behaviors.

Understanding how to use and tune a PID controller is essential for achieving precise and stable motion in humanoid robots.

## The PID Control Concept

A PID controller continuously calculates an "error" value as the difference between a desired setpoint and a measured process variable. It then applies a correction based on three terms:

1.  **Proportional (P) Term**: Accounts for the present value of the error. A larger error results in a larger corrective action.
2.  **Integral (I) Term**: Accounts for the accumulation of past errors. This helps eliminate steady-state errors.
3.  **Derivative (D) Term**: Accounts for the rate at which the error is changing. This term helps to damp oscillations and improve response time.

The control output is the sum of these three terms, multiplied by their respective gains (Kp, Ki, Kd).

**Experiment with the gains**:
*   Increase Kp: Makes the system respond faster, but can lead to overshoot and oscillations.
*   Increase Ki: Reduces steady-state error, but can increase overshoot and make the system slower to respond.
*   Increase Kd: Damps oscillations and improves stability, but too high can make the system sluggish or noisy.

## Key Concepts

*   **Setpoint**: The desired value for a controlled variable.
*   **Process Variable**: The actual measured value of the controlled variable.
*   **Error**: The difference between the setpoint and the process variable.
*   **Gains (Kp, Ki, Kd)**: Tuning parameters that determine the strength of each PID term.
*   **Overshoot**: The amount by which the system's response exceeds the setpoint.
*   **Settling Time**: The time it takes for the system's response to settle within a certain range of the setpoint.
*   **Steady-State Error**: The difference between the setpoint and the process variable after the system has settled.
